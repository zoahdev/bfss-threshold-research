Transcription evidence and notation tools

The final PDF is rebuilt from manuscript.tex and appendices/ using ../build_pdf.sh. The conversion module is specialized to these source notes; it is not a general mathematical parser. The expression map retains the original source strings and final LaTeX. The original notes are supplied for comparison, while ../technical_notes contains the separately logged prose corrections.

The display_only fixtures support the parser regression and audit scripts; their surrounding prose is not the revised manuscript. Refer to ../appendices for the authoritative editable text. The notation table explains local aliases and preserves the distinct signs of Appendix D D_0 and Appendix H D0.

Checks in this directory validate notation, token order, grouping, and regression examples. They do not establish the infinite-dimensional operator arguments.
